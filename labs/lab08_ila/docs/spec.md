# Lab 08 — On-chip Debug with ILA: Specification (v1.0)

[English](spec.md) | [Tiếng Việt](spec.vi.md)

## 1. Goal

Observe the Lab 07 design running on the board with the Vivado Integrated Logic Analyzer (ILA) and show that hardware behaviour matches simulation. Concepts: `mark_debug`, debug hub, trigger conditions, capture depth, BRAM cost of debug, comparing hardware captures with simulation waveforms.

## 2. Design Under Debug

The unchanged Lab 07 RTL (`lab07_top` and its modules). No functional change is allowed in this lab — only debug instrumentation.

## 3. Probes

| Probe | Width | Source |
|---|---|---|
| `rx_data` | 8 | `uart_rx` output |
| `rx_valid` | 1 | `uart_rx` output |
| `frame_err` | 1 | `uart_rx` output |
| `fifo_count` | 10 | `sync_fifo.count` |
| `line_state` | FSM width | `line_ctrl` state register |
| `tx_valid`, `tx_ready` | 1, 1 | `uart_tx` handshake |
| `uart_txd` | 1 | Serial output |

## 4. ILA Settings

| Setting | Value | Reason |
|---|---|---|
| Insertion method | `(* mark_debug = "true" *)` on the nets + *Set Up Debug* after synthesis | Keeps RTL unchanged apart from attributes |
| Sample clock | `clk_50m` (free-running) | ILA needs a clock that runs while debugging |
| Capture depth | 32768 samples | 32768 × 20 ns = 655 µs ≈ 7.5 UART frames (one frame = 86.8 µs), enough for a short line. Costs roughly 25 bits × 32768 ≈ 23 of the 60 BRAM36 — record the real number |
| Trigger | `rx_valid == 1 && rx_data == 8'h0D` | Start of a DRAIN phase |
| Trigger position | 128 | See the bytes before Enter |

Record the extra LUT / FF / BRAM used by the ILA (compare utilization with Lab 07).

## 5. Experiments

| ID | Experiment | Expected |
|---|---|---|
| E1 | Type `abc` + Enter | Trigger fires; `fifo_count` goes 3 → 0 while `tx_valid`/`tx_ready` handshake 5 bytes (`a b c \r \n`) |
| E2 | Compare E1 capture with the Lab 07 simulation of the same input | Same state sequence and handshake order |
| E3 | Trigger on `frame_err == 1`, change the terminal to 9600 baud and type | Frame errors captured |
| E4 | Measure one TX bit on `uart_txd` in the waveform | 434 samples per bit |
| E5 | Re-run E1 with depth 1024 and *capture control* (store only cycles where `rx_valid`, `tx_valid && tx_ready` or the state changes) | Same events captured with far less BRAM |
